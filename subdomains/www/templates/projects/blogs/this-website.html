This website's architecture at its most basic is shown below

I self host because it is fun.
Cloudflare protects my IP address and I get to save money on cloud hosting fees. In many use cases cloud is cheaper, but I have multiple docker containers for different subdomains. Add that to my desires to setup a database on the server and you can see how that would quickly become a pretty decent monthly bill for a website I host for fun.

This website runs on a python backend implemented with FastAPI.
I use FastAPI because it was quick to get up and running an not because its particularly well suited for this kind of website.

The front end is almost entirely pure HTML and CSS.
I use HTMX and vanilla JS here and there for some fun effects, but by in large I find most JS frameworks bloated. Your website does not need state management 9 times out of 10.

I bought my domain through Namecheap.com, there are plenty of other options though.
