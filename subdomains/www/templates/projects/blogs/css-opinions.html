What is bootstrap and why should I care you don't like it?

As you might have seen in the this-website article, I don't use a JS framework for this website. I think its overkill for my use case.

HOWEVER, I still want the website to look nice so CSS is important. That is where (traditionally) something like bootstrap comes in.
While many frameworks let you integrate with bootstrap or use pre-compilers like SASS, I can't do that (or more accurately choose not to since frameworks are stinky). However, bootstrap predates these frameworks. Even back in the good old days you could just import boostrap's css and have access to tons of great pre-made css classes. So why not use it?

The answer is, it is too cookie cutter and it hinders learning.
Bootstrap overuse makes your websites look cookie cutter and forces a specific formatting in exchange for quicker CSS dev. To be fair, back in the day bootstrap was just better than raw CSS for responsive web dev. Most people didn't have the tools or know how to make website that looked good on mobile and desktop. Modern CSS kind of makes this not true. There have been tons of improvement in responsive elements and design philosophy. Media queries, improved flexboxes, etc

As for how it hinders learning, when you learn bootstrap you learn bootstrap, not CSS. CSS has tons of new features in the modern day that frankly, you'll never choose to use if you're in the bootstrap bubble.

What to do instead, write everything from scratch?

Yes :)

Well at first at least. Writing it by hand will help you see why a component pattern like bootstrap is hindering. At first it can be nice, you establish a set of re-usable containers, maybe buttons too. However, as you make more pages you'll notice these component classes need to be edited in small ways to fit other pages styling (maybe different padding, margins, etc). To resolve this you'll start leveraging the Cascade part of css. Adding in classes that are basically wrappers around certain css attributes so you can quickly add details to elements without impacting global styling.

Once you get to this point, congratulations! You are officially re-creating Tailwind. Tailwind is what I will probably move to in the near future for my CSS. its like Bootstrap, but instead of giving you classes for completed and pre-formatted components, you instead have a series of classes that can be composed to style your HTML elements.

IMPORTANT: Tailwind will not make sense if you don't have experience with CSS. You need to be pretty familiar with CSS attributes to get the value from Tailwind.
